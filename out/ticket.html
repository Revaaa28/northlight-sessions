GETTING THERE

•

Commuter line or TransJakarta to Kota — the hangar is a six-minute walk from the station, following the runway-light path along the old port wall.

•

Ride-hailing drop-off and pick-up is at Gate 2 only; the port road closes to cars at 17:30.

•

Bike and motor parking inside Gate 1, free with a ticket. The night bus home leaves the gate at 01:15.

HOUSE RULES

1.

Doors at 18:00. The first set starts at 19:00 sharp — the hangar doors close during each set's first song.

2.

This ticket is a single entry for one person. The code is scanned once; screenshots of the code work, forwards don't.

3.

18+ after 21:00. Bring ID if you plan to stay for the late sets.

4.

No professional cameras. Phones are fine — the bands get the good photos from the pit photographer, free, the next day.

One night. Five sets. No headliner worship — the room is the show. Questions on the night: find any crew member with an amber wristband.
